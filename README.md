# Mitosis TikTok Video

A single 60-second vertical cartoon video about mitosis, designed to feel like entertainment first and science second.

## Concept

**POV: your cell decides to make a clone of you 💀**

The finished video is intended to be rendered as `output/mitosis.mp4` in 9:16 format.

This repository contains the first-video project, not a reusable animation engine.
